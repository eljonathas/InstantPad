# Getting help

Start with the [README](README.md), which covers installation and sound problems. For questions and ideas, use [Discussions](https://github.com/eljonathas/InstantPad/discussions). If something is broken, open a [bug report](https://github.com/eljonathas/InstantPad/issues/new?template=bug_report.yml). Security problems go through [SECURITY.md](SECURITY.md).

You can write in English or Portuguese.
