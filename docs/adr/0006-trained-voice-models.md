# 0006: A voice can speak through a model trained on it

> Where training runs is revised by [0008](0008-voices-trained-by-the-maintainers.md): the maintainers train the voices, in the cloud, and users only add the models.

The AI voices of [ADR 0003](0003-local-ai-voices.md) change the timbre of the user's voice to that of a voiceprint, heard in a few seconds of speech (OpenVoice). That runs on any computer, as the user talks, but the result only sounds roughly like the voice. Users asked for voices as close to the original as the paid voice changers make them, which takes a model trained on the voice itself.

- **RVC, trained by the user, on their own computer.** RVC v2 is the open model those voice changers are built on: MIT, with MIT base models that a voice is trained from in under an hour on an NVIDIA graphics card. Training needs PyTorch, which is gigabytes, so it runs outside the app, with the kit in `tools/voice-training`: it pins RVC by commit and every download by SHA-256, trains the voice, and exports it to ONNX in the layout the app reads. Training on the processor works and takes more than a day, which the kit says before it starts.
- **A model is added to a voice, and the user picks the engine.** The feminine voice and every cloned voice can take a trained model, from the folder the kit exported. The voice then speaks through it, and a switch takes it back to the instant engine and forth, so the user hears which suits them and their computer. A designed voice is a recipe of other voices, so it takes none.
- **The trained engine needs no learning of the user's voice.** It reads the words and the pitch, not the timbre, and moves the pitch from the median of what the user said to the pitch the voice speaks at, which the kit measures from its recordings. The pitch knob moves it further, without starting the stream over.
- **It runs as RVC's own realtime converter does.** Every 300 ms, HuBERT hears a window that reaches 300 ms before the block, YIN finds the pitch, the synthesizer speaks the end of the window, and the block is joined to the one before where the two sound most alike. YIN, not the neural pitch model RVC trains with, because that one alone takes most of the time a block has. On a 4-core 2.1 GHz processor it runs at 0.97 of real time, so a slower computer falls behind; the app then tells the user to switch to the instant engine, rather than doing it for them.
- **HuBERT is kept once.** Every voice hears with the same HuBERT, so the first model added brings it, about 380 MB, and later ones do not.
- **The feminine voice will ship trained.** The kit trains it from Hi-Fi TTS (CC BY 4.0), and once its files are published it downloads the way the other models do. Until then a user adds it like any other model.

The rules live in `crates/domain/src/cloning.rs` and `crates/domain/src/voice.rs`, and the engine in `crates/voice-ai/src/rvc.rs`.
