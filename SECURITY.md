# Security policy

## Supported versions

Only the [latest release](https://github.com/eljonathas/InstantPad/releases/latest) receives fixes. The app updates itself, so users move to it automatically.

## Reporting a vulnerability

Please do not open a public issue. Send a [private vulnerability report](https://github.com/eljonathas/InstantPad/security/advisories/new) with what the problem is, how to reproduce it and the app version, which you can find in **Settings**.

You should get a first answer within a week. Once a fix is out, we can publish the report with credit to you if you want it.

## Scope

The self-update flow replaces the running executable, and the VB-CABLE install runs a downloaded setup with elevation, so reports about either are especially useful. So are problems in how the app parses pages from the sound catalog.

VB-CABLE and the sites the app talks to belong to third parties. Please report problems in them to their owners.
